# Cartella foto dell'associazione

Metti qui le foto reali dell'associazione (JPG o WebP).

Il componente `<Foto>` le collega tramite la prop `src`, che punta a questa
cartella. Esempio: un file `public/foto/laboratorio.jpg` si richiama con
`src="/foto/laboratorio.jpg"`.

## Nomi attesi dalla galleria (modificabili in `src/UgualiNelleDiversita.jsx`)

- `laboratorio.jpg`
- `sport.jpg`
- `gita.jpg`
- `incontro.jpg`
- `musica.jpg`
- `volontari.jpg`

## Consigli

- Formato consigliato: **WebP** o **JPG** ottimizzato.
- Proporzione consigliata: **4:3** (es. 1200×900 px).
- Finché una foto non è presente, il sito mostra un segnaposto elegante
  (nessuna immagine "rotta").
- Ricordati di scrivere un `alt` descrittivo: è importante per l'accessibilità.
